CSV Format Requirements

General Rules:

  • Maximum 100 customers per upload
  • First row must be column headers
  • No empty rows or columns
  • Use comma (,) as separator
  • UTF-8 encoding recommended

Required Columns (17):

1. age (18-100)
2. income ($)
3. credit_score (300-850)
4. tenure_months (0+)
5. monthly_charges ($)
6. num_products (1-10)
7. support_calls (0+)
8. complaints_last_6m (0+)
9. avg_monthly_usage_gb (GB)
10. payment_delay_days (0+)
11. education_encoded (0-4)
12. charges_per_tenure
13. usage_per_dollar
14. complaint_rate
15. support_per_product
16. financial_stress
17. engagement_score

Optional Columns:

  • customer_name - Customer identifier (text)
  • notes - Additional comments (text)

Important Tips:

  • Numbers only (no $ or % symbols)
  • Decimals use dots (.), not commas
  • Education: 0=HS, 1=Some College, 2=Bachelor, 3=Master, 4=PhD
  • Engineered features can be calculated or estimated
charges_per_tenure = monthly_charges / tenure_months
usage_per_dollar = avg_monthly_usage_gb / monthly_charges
complaint_rate = complaints_last_6m / (tenure_months / 6)
support_per_product = support_calls / num_products
financial_stress = (monthly_charges / income * 12) - (credit_score / 1000)
engagement_score = (avg_monthly_usage_gb / 100) * (1 - complaint_rate)
